## 📘 What I Practiced

### Hello World & Print Statements
I started with simple print statements to understand how Python executes code line by line and displays output.

### Variables & Data Types
I practiced storing and using data with:
- Strings  
- Integers  
- Floats  
- Booleans  

I also performed basic calculations to see how Python handles data manipulation.

### User Input & Conditional Logic
I worked with user input and decision-making logic using `if` and `else`, which is a foundational concept for all real-world programs.
